# 知识蒸馏（Knowledge Distiller, KD-Tool）

## 项目简介

**知识蒸馏（Knowledge Distiller, KD-Tool）** 是一款专注于本地文档信息治理的工具，致力于在知识库或 RAG（检索增强生成）系统应用前，对文档进行高效的知识治理。通过去重、冲突检测、通用知识过滤等手段，帮助用户从源头提升知识库质量、提高检索效率、降低 LLM（大语言模型）推理的 token 成本和算力开销。

## 项目定位

- **非知识库/问答系统**：本工具不提供知识问答等功能，而是作为知识库/LLM 工具的前置治理环节。
- **面向个人与企业**：无论是个人知识库用户，还是企业级 RAG 应用场景，均可通过本工具提升原始信息质量。

## 解决的核心痛点

1. **数据量膨胀**：文档数量多，知识库容量快速增长，影响存储和检索效率。
2. **通用知识冗余**：大量文档包含 LLM 已具备的通用知识，导致重复和无效信息。
3. **知识冲突**：网络来源文档易出现矛盾或不一致内容，影响后续检索和推理准确性。
4. **高token/算力成本**：冗余和冲突信息增加 LLM 推理成本。
5. **个性化内容管理难**：文档频繁更新，重复输入和冲突检测增加用户负担。

## 项目愿景

通过本地化、自动化的信息治理流程，**让文档在进入知识库或被 LLM 调用前实现精炼和高效**，提升知识库质量，降低后续 AI 应用的资源消耗和知识维护成本。

---

> 本项目专注于知识治理，不提供知识问答等功能。欢迎关注、试用并提出宝贵建议！

## 项目概述
Knowledge Distiller (KD) 是一个强大的文档内容分析工具，采用分层架构设计(UI, Core, Analysis, Processing, Storage)，使用先进的语义分析技术，能够：
- 通过Czkawka进行文件级预过滤
- 实现MD5 → SimHash（开发中） → SBERT三层内容去重
- 提供灵活的命令行交互界面
- 提供UI界面(开发中)
- 通用知识（计划中）
- 知识冲突（计划中）
