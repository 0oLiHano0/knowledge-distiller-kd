**任务ID:** `KD-LOGGING-001`

---

**一、 背景信息:**

*   项目需要一个统一、可配置、功能强大的日志系统。Loguru 提供了简洁的 API 和灵活的配置选项（如结构化 JSON 输出、文件轮转）。我们需要将 Loguru 的配置与应用的整体配置系统 (`AppConfig`) 集成，并通过依赖管理工厂 (`core/factories.py`) 提供配置好的 logger 实例。

----

**二、任务目标 (Objective):**

*   在 `core/factories.py` 中实现 `create_logger` 函数，该函数根据 `AppConfig` 中的 `LoggingConfig` 设置来配置并返回一个 Loguru logger 实例。
*   确保 Loguru 能够根据配置输出到指定文件（JSON格式）和控制台。

---

**三、文件位置:**

*   `knowledge_distiller_kd/core/factories.py` (修改 `create_logger`)
*   `knowledge_distiller_kd/core/config.py` (读取 `LoggingConfig`)
*   `requirements.txt` / `pyproject.toml` (确保 `loguru` 存在)
*   (隐式) `logs/` 目录 (需要存在或由 Loguru 创建)

---

**四、子任务列表:**

1.  **确保 Loguru 依赖:** 检查并确保 `loguru` 已添加到项目依赖文件 (`requirements.txt` 或 `pyproject.toml`) 中。
2.  **实现 `create_logger` 函数:** 在 `core/factories.py` 中完成 `create_logger(config: AppConfig)` 函数的实现：
    *   从 `config` 参数中获取 `logging_config = config.logging`。
    *   导入 `logger` from `loguru` 和 `sys`。
    *   **移除默认处理器:** 调用 `logger.remove()` 以移除 Loguru 默认的控制台输出处理器，避免重复输出。
    *   **添加文件 Sink:** 调用 `logger.add()` 添加文件日志：
        *   `sink=logging_config.log_file_path`
        *   `level=logging_config.log_level.upper()`
        *   `rotation=logging_config.log_rotation`
        *   `retention=logging_config.log_retention`
        *   `serialize=logging_config.log_serialize_json`
        *   `encoding='utf-8'` (推荐)
        *   `enqueue=True` (可选，用于异步日志记录，提高性能)
    *   **添加控制台 Sink:** 调用 `logger.add()` 添加控制台输出：
        *   `sink=sys.stderr`
        *   `level=logging_config.log_level.upper()` (或可以单独配置控制台级别)
        *   `serialize=False` (通常控制台希望是易读格式)
        *   `colorize=True` (可选，美化控制台输出)
    *   返回配置好的 `logger` 对象。

---

**五、验收标准:**

1.  `core/factories.py` 中的 `create_logger` 函数已实现。
2.  调用 `create_logger` 函数返回一个正确配置的 `loguru.logger` 实例。
3.  应用程序运行时，日志信息根据 `LoggingConfig` 中的设置被写入指定的文件（JSON 格式）。
4.  日志信息根据 `LoggingConfig` 中的设置被输出到控制台（易读格式）。
5.  日志级别、轮转、保留策略符合配置。
6.  单元测试已添加，用于验证 `create_logger` 是否正确调用了 `logger.add` 并使用了配置中的参数（可能需要 Mock `logger.add`）。
