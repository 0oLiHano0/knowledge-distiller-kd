## SQLite 数据库核心表结构与占位表设计

### 一、核心表结构

1. **documents** 表：

   ```sql
   CREATE TABLE documents (
     id           INTEGER PRIMARY KEY AUTOINCREMENT,
     path         TEXT NOT NULL UNIQUE,
     file_hash    TEXT NOT NULL,
     type         TEXT,
     size         INTEGER,
     ctime        DATETIME,
     mtime        DATETIME,
     ingest_time  DATETIME DEFAULT CURRENT_TIMESTAMP,
     status       TEXT
   );
   ```

2. **blocks** 表：

   ```sql
   CREATE TABLE blocks (
     id                 INTEGER PRIMARY KEY AUTOINCREMENT,
     document_id        INTEGER NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
     content_hash       TEXT,
     simhash            TEXT,
     text               TEXT,
     raw_element_type   TEXT,
     processing_status  TEXT,
     metadata           JSON
   );
   ```

3. **analyses** 表：

   ```sql
   CREATE TABLE analyses (
     id             INTEGER PRIMARY KEY AUTOINCREMENT,
     block_id       INTEGER NOT NULL REFERENCES blocks(id) ON DELETE CASCADE,
     analysis_type  TEXT NOT NULL,
     score          REAL,
     details        JSON
   );
   ```

4. **decisions** 表：

   ```sql
   CREATE TABLE decisions (
     id                    INTEGER PRIMARY KEY AUTOINCREMENT,
     block_id              INTEGER NOT NULL REFERENCES blocks(id) ON DELETE CASCADE,
     decision_type         TEXT NOT NULL,
     duplicate_of_block_id INTEGER REFERENCES blocks(id),
     timestamp             DATETIME DEFAULT CURRENT_TIMESTAMP,
     comment               TEXT
   );
   ```

---

### 二、占位表结构

1. **duplicate\_file\_groups**（Czkawka 重复文件组）

   ```sql
   CREATE TABLE duplicate_file_groups (
     group_id    INTEGER PRIMARY KEY AUTOINCREMENT,
     document_id INTEGER NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
     file_path   TEXT    NOT NULL,
     is_original BOOLEAN NOT NULL DEFAULT FALSE
   );
   ```

2. **sessions**（分析会话记录）

   ```sql
   CREATE TABLE sessions (
     id         INTEGER PRIMARY KEY AUTOINCREMENT,
     start_time DATETIME NOT NULL,
     end_time   DATETIME,
     mode       TEXT    NOT NULL,   -- 'pre-filter' | 'full'
     summary    JSON               -- 扫描/分析结果摘要
   );
   ```

3. **export\_jobs**（导出任务）

   ```sql
   CREATE TABLE export_jobs (
     id           INTEGER PRIMARY KEY AUTOINCREMENT,
     session_id   INTEGER REFERENCES sessions(id) ON DELETE SET NULL,
     export_type  TEXT    NOT NULL,  -- 'json' | 'csv'
     output_path  TEXT    NOT NULL,
     status       TEXT    NOT NULL,  -- 'pending' | 'done' | 'failed'
     created_at   DATETIME DEFAULT CURRENT_TIMESTAMP
   );
   ```

---

> **说明**：
>
> * 核心表结构 (`documents`, `blocks`, `analyses`, `decisions`) 支撑当前所有 CLI 与分析功能。
> * 占位表 (`duplicate_file_groups`, `sessions`, `export_jobs`) 为未来 UI 的“重复文件管理”、“历史纪录”、“导出任务”提供基础数据结构。
> * 其他多用户或配置表暂不考虑，在本地单用户场景下不需引入。
